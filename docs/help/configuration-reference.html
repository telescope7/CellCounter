Tracking Configuration Reference

Detailed meaning of each runtime parameter, how it is loaded, and how value changes affect behavior.

Where Configuration Is Applied

  • Session defaults: CellCounter.properties is loaded at startup for GUI and headless mode.
  • GUI runtime: the inline Settings bar edits the active session configuration.
  • Headless override: CLI flags and --tracking-config=<file> can override startup defaults.
The application expects CellCounter.properties to exist and be valid. It is the required default source for startup tracking values.

Parameter-by-Parameter Effects

Key Description If Increased If Decreased
maxFramesDisappeared How many consecutive frames a track can go unmatched before it is retired. Tracks survive detector dropouts longer, but stale IDs can linger. Tracks terminate sooner, which reduces lingering IDs but can fragment real cells.
rightEdgeExitZonePercent Width of the right-edge exit corridor as a percent of the frame. Tracks that disappear in this zone retire quickly instead of lingering as misses. Set to 0 to disable. A larger exit corridor retires disappearing edge tracks sooner. A smaller corridor keeps edge tracks alive longer, which can preserve borderline detections but also allows more lingering misses.
minContourArea Minimum contour area allowed to count as a cell candidate. Rejects small speckle noise more aggressively. Allows smaller or dimmer candidates through at the cost of more false positives.
maxRectCircumference Maximum allowed perimeter of a contour bounding rectangle. Admits larger blobs and merged objects. Rejects larger artifacts sooner.
maxVerticalDisplacementPixels Maximum up/down motion allowed when linking a detection to an existing track. Tolerates more drift or slight tilt in the flow direction. Forces straighter horizontal continuity.
minHorizontalMovementPixels Minimum horizontal movement required for a valid association. Enforces stronger forward motion and can reject slow movers. Allows more stall tolerance and more leftward centroid jitter.
maxAssociationDistancePixels Maximum centroid distance allowed to link a detection to an existing track. Helps bridge larger jumps and temporary detector instability. Tightens identity matching but increases the chance of broken tracks.
mog2HistoryFrames How much frame history MOG2 uses to model the background. Background adapts more slowly and may preserve slow movers longer. Background adapts faster and can absorb slow or stationary cells.
mog2VarThreshold MOG2 sensitivity threshold for separating foreground from background. Produces a more conservative foreground mask. Produces a more sensitive mask with higher noise risk.
mog2DetectShadows Enables or disables MOG2 shadow classification. When enabled, possible shadows are modeled separately. When disabled, the mask is simpler and often easier to interpret for high-contrast videos.
morphologyKernelSize Kernel size used for morphology cleanup. The app normalizes it to an odd value. Smooths detections more strongly and can merge nearby objects. Preserves more detail but may leave more noise fragments.
morphologyOpenIterations Opening passes used to remove small bright speckles. More cleanup, but more erosion of weak detections. Less cleanup, but more speckle survives.
morphologyDilateIterations Dilation passes used after opening to strengthen blobs. Bridges small gaps and strengthens weak masks, but can merge nearby cells. Preserves separation, but fragmented detections may remain broken apart.
normalizedMaskThreshold Threshold applied after the foreground mask is normalized to 0-255. Makes foreground acceptance stricter. Makes foreground acceptance more permissive.
trackerAlgorithm Assignment strategy used when linking detections to existing tracks. Hungarian optimizes the full assignment set globally. Greedy is simpler and faster, but can be less globally optimal in crowded frames.

Normalization Rules

  • maxFramesDisappeared, mog2HistoryFrames, and morphology iteration counts are integer values.
  • morphologyKernelSize is forced to an odd value and at least 1.
  • normalizedMaskThreshold is clamped to [0, 255].
  • Negative minHorizontalMovementPixels values are valid and allow leftward centroid jitter.

How To Use Settings Safely

  • Tune segmentation first, then tune track association behavior.
  • Use the foreground pane as the primary diagnostic surface.
  • Pause on representative frames before changing multiple values in sequence.
  • When major settings change, rerun analysis before exporting.
