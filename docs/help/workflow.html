Standard Workflow Analysis

From session setup through dual-pane review, analysis, and export.

Back to Help Home

1. Prepare the Session

You can open Settings even before a video is loaded. This is useful when you already know the parameter set you want to start with.

Without a loaded video, the Settings bar can still be edited and applied, but preview rendering is unavailable until a video is initialized.

2. Open the Source Video

Click Open Video, select a microscopy video, and verify the first frame renders in both the Raw Input + Tracks and Foreground + Tracks panes.

  • The frame readout displays progress as Frame: X/Y.
  • The raw pane is kept clean by default for visual reference.
  • The foreground pane shows the diagnostic overlays used for tuning and review.

3. Configure Settings

Use Settings while paused to expand the compact inline settings bar below the playback controls.

  • Adjust segmentation parameters first: background history, variance threshold, mask threshold, contour area, and morphology.
  • Then refine tracking rules: association distance, disappearance budget, vertical drift, horizontal motion constraint, and assignment algorithm.
  • Hover any setting label or control to see a tooltip that explains the parameter and its practical effect.
  • Click Apply to make the values active for the session, or Hide to collapse the bar.

4. Analyze the Video

Choose one of two paths:

  • Play/Analyze: live playback with frame-by-frame tracking.
  • Fast Analyze: full-pass analysis without realtime playback timing.

Use Step or the keyboard shortcuts for frame-by-frame checks.

Shortcuts: P or K for play/pause, Esc for pause, hold Space for repeated stepping, and . or Right Arrow for single-step advance.

5. Review the Visual Diagnostics

  • Raw Input + Tracks: clean reference image, optionally mirrored with overlays when Mirror Tracking is enabled.
  • Foreground + Tracks: background-subtracted tracking view with history tails and future match regions.
  • Track Start Distribution: histogram plus cumulative distribution of track-start times.
  • Speed Distribution: histogram plus cumulative distribution of observed instantaneous speeds.

6. Save Results

Click Save Results and provide metadata plus a base filename. The app writes:

  • <base>_analysis.csv
  • <base>_footprint.csv
Re-run analysis after major parameter changes so the exported outputs match the final settings.

7. Optional Validation Workflow

  • Open the header Simulator link to generate synthetic videos and truth CSVs.
  • Run the evaluator against simulator truth data.
./run-ground-truth-eval.sh --video=... --truth-events=... \
  --tracking-config=CellCounter.properties --output-prefix=/tmp/eval01
