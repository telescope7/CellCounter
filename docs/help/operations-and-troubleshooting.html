Recommended Tuning Order

  1. Pause on a frame with representative background texture and cell density.
  2. Open Settings and watch the foreground pane while adjusting detection thresholds.
  3. Raise minContourArea until tiny background speckles are mostly suppressed.
  4. Adjust normalizedMaskThreshold and mog2VarThreshold for clean cell fill.
  5. Refine morphology to remove speckle without merging adjacent cells.
  6. Then tune association and disappearance parameters to improve ID continuity.

Common Issues

SymptomLikely CauseAction
Settings opens but no preview appears No video is loaded yet This is expected. Adjust or apply settings, then load a video to enable frame preview.
OpenCV load error Native library not discoverable Use the packaged app output or validate the OpenCV runtime path and loader fallback.
Too many tiny false detections Threshold or contour filtering is too permissive Increase minContourArea, increase normalizedMaskThreshold, and review morphology opening.
Tracks break too often Association constraints are too strict or segmentation is unstable Review maxAssociationDistancePixels, maxFramesDisappeared, and foreground quality first.
Foreground pane shows weak or disappearing cells MOG2 or morphology is absorbing slow/stationary objects Review mog2HistoryFrames, mog2VarThreshold, contour area, and morphology settings.

Testing and Validation

Before packaging or sharing a new build, run the project test suite:

mvn -Dmaven.repo.local=.m2/repository test
  • Unit tests cover tracking configuration loading, assignment strategies, export logic, geometry helpers, and chart refresh cadence.
  • After UI-heavy changes, also validate a manual workflow: open video, open Settings, run Play/Analyze, run Fast Analyze, and save results.

Packaging and Distribution

Use the project packaging script to bundle jars, runtime dependencies, properties, icons, and help docs:

./package-app.sh --type=app-image

For DMG generation, signing, and notarization commands, see the project README.md.
