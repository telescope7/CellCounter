UI Button and Control Reference

Detailed description of each control in the main Cell Counter window.

Back to Help Home

Top-Right Header Controls

ControlWhat It Does
Simulator Opens Cell Simulation Studio from the header link to generate synthetic videos and ground truth files.
Help Opens this local HTML documentation set in the system browser.
Status Chip Shows pipeline state with a color-coded indicator dot. Common values: Waiting for file, Ready, Playing, Paused, Seeking, Fast Analyze, Configured, Complete, Error.

Controls Card: Primary Row

ButtonBehavior
Open VideoOpen a file chooser and initialize video + analysis pipeline. Shortcut: O.
Fast AnalyzeRun accelerated full-pass analysis without realtime playback timing. Shortcut: F.
Play/AnalyzeToggle realtime play/pause while tracking each frame. Shortcuts: P or K; Esc pauses only.
StepAdvance exactly one frame while paused. Shortcuts: hold Space for repeated stepping, or use . / Right Arrow for single-frame advance.
ReplayReset analysis and frame pointer to frame 1 using current settings. Shortcut: R.
Save ResultsSave both analysis and footprint CSVs in one action. Shortcut: S.

Controls Card: Secondary Row

ControlBehavior
Frame label (Frame: X/Y) Displays current frame index and total frame count.
Video position slider Shows frame progress only. It is intentionally read-only and does not support scrubbing/dragging.
Playback Speed label (Playback Speed: Nx) Displays active playback rate for realtime mode.
Playback speed slider Adjust play rate (0.1x to 5.0x).
Settings Open the live settings dialog for segmentation/tracking parameters. Shortcut: T.
Mirror Tracking When enabled, the raw pane mirrors the richer foreground tracking overlays, including full history tails and future match regions.

Visualization Panels

PanelWhat You See
Raw Input + TracksCurrent raw microscopy frame only. If Mirror Tracking is enabled, it mirrors the full foreground tracking overlays, including labels, boxes, history tails, and future match regions.
Foreground + TracksCurrent background-subtracted foreground frame with the same live tracking overlays plus full history trails and future match regions.
Track Start DistributionHistogram + cumulative distribution of track-start times.
Speed DistributionHistogram + cumulative distribution of observed speeds.

Settings Dialog Controls

Dialog ControlBehavior
Parameter slidersAdjust segmentation/tracking parameters and trigger refreshed preview in both the raw and foreground panes when released.
Enable MOG2 shadowsToggle shadow classification in background subtraction.
Tracker AlgorithmSelect the assignment method used to match detections to existing tracks during analysis.
Apply ParametersApply current dialog values to active runtime configuration.
Reset SlidersRestore sliders to currently applied configuration.
CloseClose dialog and return to main window.

When preview rendering is in progress, slider and parameter input controls are temporarily disabled to prevent race conditions.

For exact parameter behavior, see Configuration Reference.
