UI Button and Control Reference

Detailed description of the current Cell Counter interface, status states, and keyboard shortcuts.

Back to Help Home

Top-Right Header Controls

ControlWhat It Does
Simulator Opens Cell Simulation Studio from the header link to generate synthetic rolling-cell videos and ground-truth CSVs.
Help Opens the local HTML help set in the system browser.
Status Chip Shows the current pipeline state. Common values include Waiting for file, Ready, Playing, Paused, Fast Analyze, Settings, Complete, and Error.

Main Controls Row

ControlBehavior
Open VideoOpens a file chooser and initializes the shared analysis pipeline for the selected video. Shortcut: O.
Fast AnalyzeRuns a full-pass analysis quickly without realtime playback timing. Shortcut: F.
Play/AnalyzeToggles live playback and analysis. Shortcuts: P or K; Esc pauses only.
StepAdvances exactly one frame while paused. Hold Space for repeated stepping, or use . / Right Arrow for a single-frame step.
ReplayResets the current video analysis and returns to frame 1 using the active runtime settings. Shortcut: R.
Save ResultsSaves both analysis and footprint CSV outputs in one action. Shortcut: S.

Secondary Controls Row

ControlBehavior
Frame label (Frame: X/Y) Displays the current frame number and total frame count. This is a read-only progress indicator and no longer acts as a scrubber.
Playback Speed label (Playback Speed: Nx) Displays the active realtime play rate.
Playback speed slider Adjusts live playback speed from 0.1x to 5.0x.
Settings Shows or hides the inline settings bar. Settings can be opened before a video is loaded; preview rendering becomes available after a video is initialized. Shortcut: T.
Mirror Tracking When enabled, the raw pane mirrors the same rich overlays shown in the foreground pane, including labels, history tails, and future match regions.

Visualization Panels

PanelWhat You See
Raw Input + TracksThe raw microscopy frame. By default this stays visually clean. If Mirror Tracking is enabled, it mirrors the same rich overlays used in the foreground pane.
Foreground + TracksThe background-subtracted diagnostic view with current tracks, full history tails, and future match regions.
Track Start DistributionHistogram plus cumulative distribution of track-start times.
Speed DistributionHistogram plus cumulative distribution of observed instantaneous speeds.

Settings Bar Controls

ControlBehavior
Numeric steppersCompact integer up/down controls for segmentation and tracking parameters. Changing a value requests a refreshed preview when a video is available.
Hover helpEvery setting label and control exposes a tooltip describing what the parameter does and how changing it affects tracking.
Tracker AlgorithmSelects the assignment strategy used to match detections to existing tracks.
ApplyApplies the current settings bar values to the active session configuration.
ResetRestores the inputs to the last applied runtime configuration.
HideCollapses the settings bar without discarding the applied configuration.

Inputs are temporarily disabled while a preview is being rendered to prevent overlapping updates.

For exact parameter semantics, see Configuration Reference.
