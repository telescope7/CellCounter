Quick Start (GUI)

  1. Optionally open Settings before loading a video to preconfigure the session.
  2. Click Open Video and choose a source file.
  3. Review the Raw Input + Tracks and Foreground + Tracks panes together.
  4. Use Settings on a representative paused frame.
  5. Run with Play/Analyze or Fast Analyze.
  6. Save both output CSVs with Save Results.

Shortcuts: O open, P/K play-pause, hold Space step, ./Right Arrow single-step, R replay, T settings, H help.

Quick Start (Headless)

java -jar cellcounter.jar /path/video.avi /tmp/run01 \
  --tracking-config=/path/CellCounter.properties

Headless mode uses the same tracking engine and config semantics as the GUI.

Current UI Behavior

  • The frame readout is a text indicator only: Frame: X/Y.
  • The raw pane stays visually clean unless Mirror Tracking is enabled.
  • The foreground pane is the main diagnostic surface for tracks, history, and future match regions.
  • The status chip reports pipeline state such as Waiting for file, Paused, Fast Analyze, or Complete.
